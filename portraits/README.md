# Character portraits

Add Sophia, Leo, Ken, Veronica, and Catherine's approved photos here.

In `../data.js`, set the matching person's `portrait` field to a path such as `portraits/sophia.jpg`. Set `portraitPosition` to control the crop, for example `50% 35%`.

One field supplies the map node, person panel, people list, and related-person links. Until a photo is supplied, the person's initial is shown. A failed image safely falls back to the same initial. No synthetic faces or stock portraits are used.
